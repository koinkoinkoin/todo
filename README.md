# To-do · IP Paris

Interface de la to-do (une seule page HTML), publiée via GitHub Pages.
Ce dépôt ne contient **aucune donnée** : la liste (`todo.json`) est dans le dépôt privé `todo-data`
et est lue/écrite via l'API GitHub avec un jeton fine-grained stocké uniquement dans le navigateur de chaque appareil.
